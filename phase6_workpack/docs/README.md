# Phase 6 research workpack

Files in `scripts/` are **new** scripts to copy to `PhIRE/scripts/` on Spark. All existing PhIRE source and tagged release files remain unchanged. Read `phase6_cv_pers_ablation_protocol.md` before running.

This package provides a 2x2 fixed-pair CV/PERS factorial training launcher, a static test, and figure generation using frozen Phase5E summary CSVs. It does **not** contain newly trained models, new PD distances, or modified manuscript data.
